# Contributing to Project Cost & Schedule Risk Prediction Platform

Thank you for considering contributing to Project Cost & Schedule Risk Prediction Platform.

## Guidelines

1. Fork the repository and create your branch from `main`.
2. Follow standard Python (PEP 8) and clean JavaScript practices.
3. Ensure all new features include corresponding unit tests in `tests/`.
4. Run `make test` before submitting a pull request.
5. Provide clear, descriptive commit messages.

## Submitting Pull Requests

1. Open a pull request targeting `main`.
2. Reference any related issues in the PR description.
3. Ensure all CI test suites pass cleanly.
